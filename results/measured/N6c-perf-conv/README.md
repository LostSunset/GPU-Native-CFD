# N6c：gncRhoSimple 的效能，N-027 之後（g02）

日期：2026-10-24（UTC 2026-10-23）。主機：**g02**，2 × AMD EPYC 9684X（192 核）＋ NVIDIA L40（GPU3）。驅動：
`scripts/n6c_g02.sh`（紀錄 `../N6c-L3/N6c-g02-driver.log`）。建置同 `../N6c-L3/`（原始碼雜湊 `587a0b4f…`）。
與 `../N6b-perf-conv/` 的差別：效能版的 AMG 套用格式與單次啟動歸約（N-027）。OpenFOAM、SPUMA 沿用同日的
`N6-perf-*`、`N6-perf-of32`（**主機 CPU 有其他使用者的 MPI 作業，load 約 104／192 核**），brae 為
`../BRAE-perf/`（同一張 L40、同樣網格）。紀錄：`N6c-perf-r1`、`-r2`、`-r4`、`-r8`、`-conv`。

括號內為 p 的平均線性迭代次數。gnc 為求解器的迴圈時間（迴圈中不寫場）；brae 為兩次執行的牆鐘差（三次中位數）。

- `gncamg` 對 OpenFOAM 單核：7.0、29、123、221 倍；對 32 核：4.3、8.5、23、16 倍；對 SPUMA：217、683、2210、
  2550 倍；對 brae：0.76、0.73、0.98、1.21 倍的速度（102 萬格比 brae 快 1.2 倍）。比 N6b 快 1.45–1.67 倍。
- `gncfast`（多色 DIC，不經過 AMG）因單次啟動歸約也變快（0.0191 → 0.0144 s 等）。
- 參考次序版（gnc）不經過這些改動，數字與 N6b 相同（在量測誤差內）。
