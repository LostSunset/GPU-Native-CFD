- B：兩色只在 64,000 格可量到（4%）；DILU／DIC 的掃描在小網格本來就以啟動為主。
- C：粗層 Jacobi 不需分色、一次啟動掃完整層，p 的迭代數多 11–19%，但每次 V-cycle 便宜，在 64,000 格以上
  再快 1.08–1.30 倍。
- Welsh–Powell 在這個設定下不起作用：第 0 層是二分圖（兩色），第 1 層起用 Jacobi 不需著色，迭代數完全相同；
  C 與完整設定在 16,000 格的差（7%）是重複量測的差異，可作為小網格計時的誤差範圍。
